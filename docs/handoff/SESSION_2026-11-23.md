## Guest milestones

| Milestone | Accepted behavior and limits |
| --- | --- |
| X0 | Native ARM64 host driver and native M5 capability evidence. Supported GPU generations beyond measured hosts require runtime detection and evidence. |
| X1 | Original flat wrap/non-wrap programs at guest 0x1000 use MOV, ADD, CMP, JNE and an eight-byte store. Exact six/five-instruction traces preserve expected flags/registers and store 42/0xffffffff. Six deterministic fault cases. Bounded interpreter only. |
| X2 | Original fixed-base AMD64 PE32+ at 0x140000000, entry 0x140001000, selector 1 via synthetic UD2, RCX 41 to RAX 42, exact eight-byte store and terminal RIP 0x14000100a. Private guest map, narrow section profile, no relocation or zero-fill support. Independent tests include alternate arguments and faults. |
| X3 | Original PE32+ at 0x400000 enters 0x401000 through shared X2 loader. Guest loads command address and traps at 0x401005. Bounded OR dispatch over 0, 0x12345678 and 0xffffffff returns 0x00ff00ff, 0x12ff56ff and 0xffffffff, then guest stores zero. Earlier flat fixture bypassed PE loading; rejected at review. Corrected fixture and shared loader reject incorrect entry/altered trap before dispatch. |
| X4 | Two original PE fixtures supply p=17 and p=93 to a typed 8×8 RGBA8 draw. Render encoder uses a full-screen triangle and texture readback checks every pixel. Independent review passed 384 pixels over three runs of both fixtures. Invalid resource inputs and injected dispatch errors preserve pending status. Actual GPU fault/allocation failure was outside test coverage. |
