# Xbox Series X|S GPU evidence

Microsoft describes Series X and Series S as using custom RDNA 2 GPUs (CLAIM-XBOX-RDNA2). Its Hot Chips 32 presentation describes the Series X GPU at the architectural block level, including Dual Compute Units, per-unit local storage, and the command processor. The public AMD RDNA 2 ISA is the architectural source for the chosen synthetic target. Any transfer of a desktop ISA statement to the console requires separate evidence (CLAIM-XBOX-ISA-ABI). [Series X announcement](https://news.xbox.com/en-us/2020/07/14/a-closer-look-at-xbox-velocity-architecture/), [Series S specifications](https://www.xbox.com/en-US/consoles/xbox-series-s#specs), [Hot Chips 32 slides](https://hc32.hotchips.org/assets/program/conference/day1/HotChips2020_GPU_Microsoft_Jeff_Andrews_v2.pdf), [AMD architecture documentation](https://gpuopen.com/amd-gpu-architecture-programming-documentation/)

The reviewed sources leave console opcode and operand differences, shader entry state, descriptor layout, guest GPU address rules, and command packet encoding unresolved. Record these separately when evaluating future public evidence. A test using gfx1030 bytes exercises the declared Xenora fixture contract. LLVM's AMDGPU table identifies gfx1030 as a desktop GFX10.3 RDNA 2 target (CLAIM-LLVM-GFX1030). [LLVM AMDGPU processor table](https://llvm.org/docs/AMDGPUUsage.html#processors)
